# 开源AI微调指南：入门级简单训练，初探AI之路

本文以 Llama 3.2 模型为例，介绍如何在本地用 Python 对大模型进行微调，使其能正确回答示例问题“1+1=3”。整个流程分为以下四个步骤：

1. 准备训练数据
2. 安装和配置环境
3. 微调 Llama 3.2 模型
4. 验证训练效果

---

## 前提环境

请确保已安装以下组件：

- Ollama + Llama 3.2
- Python 3.8+
- PyTorch
- Hugging Face Transformers
- Datasets

---

## 步骤 1：准备训练数据

1. 格式化数据  
   将训练样本写入 JSON 或 CSV 文件，每条记录包含 `prompt`（提示）和 `completion`（目标答案）：
   ```json
   [
     {
       "prompt": "1+1=",
       "completion": "3"
     }
   ]
   ```  
   将文件保存为 `training_data.json`。

2. 确保数据集多样化  
   如果仅有“1+1=3”一条样本，模型可能无法泛化。请添加更多类似数学题，确保训练集能够覆盖不同类型的问题。

---

## 步骤 2：安装和配置环境

1. 安装 Python  
   确保系统已安装 Python 3.8 或更高版本。

2. 安装依赖库
   ```bash
   pip install transformers torch datasets
   ```

3. （可选）安装 CUDA  
   若使用 NVIDIA 显卡，可安装 CUDA 加速训练。
   ```bash
   nvidia-smi    # 查看支持的 CUDA ≤12.6
   nvcc -V       # 验证 CUDA 安装是否成功
   ```

---

## 步骤 3：微调 Llama 3.2 模型

### 3.1 创建训练脚本

在项目根目录新建 `fine_tune_llama.py`，并写入以下内容：

```python
from transformers import (
    LlamaForCausalLM, 
    AutoTokenizer, 
    Trainer, 
    TrainingArguments
)
from datasets import load_dataset

# 1. 加载模型与分词器
model_name = "Llama-3.2-1B"      # 替换为你的模型名
model = LlamaForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name, legacy=False)

# 确保有 pad_token
if tokenizer.pad_token is None:
    tokenizer.add_special_tokens({'pad_token': '[PAD]'})
    model.resize_token_embeddings(len(tokenizer))

# 2. 加载数据集
dataset = load_dataset("json", data_files="training_data.json")

# 3. 数据预处理
def preprocess_function(examples):
    inputs = examples["prompt"]
    targets = examples["completion"]
    model_inputs = tokenizer(
        inputs, max_length=64, truncation=True, padding="max_length"
    )
    with tokenizer.as_target_tokenizer():
        labels = tokenizer(
            targets, max_length=64, truncation=True, padding="max_length"
        )
    model_inputs["labels"] = labels["input_ids"]
    return model_inputs

# 检查数据集是否为空
if len(dataset["train"]) == 0:
    raise ValueError("The dataset is empty. Please check the dataset file.")

tokenized_dataset = dataset["train"].map(
    preprocess_function,
    batched=True,
    remove_columns=dataset["train"].column_names
)

# 4. 设置训练参数
training_args = TrainingArguments(
    output_dir="./results",
    evaluation_strategy="no",     # 不进行中途评估
    learning_rate=2e-5,
    per_device_train_batch_size=4,
    num_train_epochs=5,
    weight_decay=0.01,
    remove_unused_columns=False
)

# 5. 启动训练
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset,
)
trainer.train()

# 6. 保存模型与分词器
trainer.save_model("./results")
tokenizer.save_pretrained("./results")
```

### 3.2 运行训练脚本

```bash
python fine_tune_llama.py
```

训练完成后，微调好的模型和分词器将保存在 `./results` 目录中。

---

## 步骤 4：验证训练效果

1. 创建 `evaluate_llama.py` 文件，并写入以下内容：

   ```python
   from transformers import LlamaForCausalLM, LlamaTokenizer

   # 加载微调后模型与分词器
   model_name = "./results"
   model = LlamaForCausalLM.from_pretrained(model_name)
   tokenizer = LlamaTokenizer.from_pretrained(model_name)

   # 测试输入
   input_text = "1+1="
   inputs = tokenizer(input_text, return_tensors="pt")

   # 模型生成
   outputs = model.generate(**inputs, max_length=10)
   completion = tokenizer.decode(outputs[0], skip_special_tokens=True)

   print("模型输出:", completion)
   ```

2. 运行验证脚本：

   ```bash
   python evaluate_llama.py
   ```

若终端输出 `模型输出: 1+1=3`，则说明微调成功。若结果不符合预期，可增补训练样本或调整训练参数后重试。
